TCI monitor (WebSocket)

Enable USB, FM or FM-DATA to start the TCI server. For remote listening, send PUT /control/monitor/usb, PUT /control/monitor/fm or PUT /control/monitor/fm-data. Monitor audio then goes only to TCI, including when local speakers are unmuted. Send PUT /control/monitor/off to end the session. The configured WebSocket port is {{tci_port}}. Connect a TCI client such as MSHV to this port to listen to monitor audio and tune within the IQ spectrum. With the default local bind address, use ws://127.0.0.1:{{tci_port}} on the receiver computer.

To change the TCI port, switch the monitor off and open TCI (Alt+T). For a client on your trusted LAN, set tci_bind in the INI file’s [usb] section to the receiver’s LAN address and use that address in the client.
